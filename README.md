# URL Shortener — Microservices Architecture

A college assignment project demonstrating microservices design: URL shortening, redirection, and analytics — all behind a single API Gateway.

## Architecture

```
Client → API Gateway (:8080)
            ├── POST /api/urls          → URL Service (:3001)
            ├── GET  /api/analytics/*   → Analytics Service (:3003)
            └── GET  /:shortCode        → Redirect Service (:3002)
                                                └── (notifies) → Analytics Service
```

Each service has its own SQLite database file stored in a Docker volume.  
URL Service and Redirect Service share the same `urls.db` volume.

## Setup & Run

### Prerequisites
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (includes Docker Compose)

### Start all services

```bash
docker-compose up --build
```

All four containers start automatically. The gateway is available at **http://localhost:8080**.

### Stop

```bash
docker-compose down
```

To also wipe the database volumes:

```bash
docker-compose down -v
```

## API Endpoints

### 1. Shorten a URL

**POST** `http://localhost:8080/api/urls`

```bash
curl -X POST http://localhost:8080/api/urls \
  -H "Content-Type: application/json" \
  -d '{"originalUrl": "https://www.google.com"}'
```

Response:
```json
{
  "shortCode": "1",
  "shortUrl": "http://localhost:8080/1"
}
```

---

### 2. Redirect to Original URL

**GET** `http://localhost:8080/:shortCode`

```bash
curl -L http://localhost:8080/1
```

Responds with HTTP `302` and redirects to the original URL.  
Also fires a background request to the Analytics Service.

---

### 3. Get Analytics

**GET** `http://localhost:8080/api/analytics/:shortCode`

```bash
curl http://localhost:8080/api/analytics/1
```

Response:
```json
{
  "shortCode": "1",
  "requestCount": 3,
  "accessTimestamps": [
    "2024-01-15 10:30:01",
    "2024-01-15 11:05:44",
    "2024-01-15 12:00:22"
  ]
}
```

## Database Schema

### `urls` table (url-service / redirect-service)

| Column | Type | Description |
|---|---|---|
| id | INTEGER PK | Auto-increment |
| short_code | TEXT UNIQUE | Base62 encoded ID |
| original_url | TEXT | Full original URL |
| created_at | DATETIME | Creation timestamp |

### `analytics` table (analytics-service)

| Column | Type | Description |
|---|---|---|
| id | INTEGER PK | Auto-increment |
| short_code | TEXT | Reference to short code |
| accessed_at | DATETIME | When the redirect happened |

---

## Base62 Encoding

Short codes are generated by Base62-encoding the SQLite auto-increment row ID.  
Characters used: `0-9 a-z A-Z` (62 total).

| ID | Short Code |
|---|---|
| 1 | `1` |
| 62 | `a` |
| 3844 | `10` |

This guarantees uniqueness with no collision checks needed.
